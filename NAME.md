# Package name

**Chosen:** `hsi-core`

**Why:** Short, GitHub-safe, and matches the roadmap’s “HSI core” lane. The product is Human Super Intelligence. Aksh Health, HSI Clinical, ISI and HSI Trials are governed modules of that one product. The package does not couple their application repositories.

Checked: no `hsi-core` / `evidedge` / `systems-bridge` / `aksh-isi-core` name collision on the public package index at the time of the original naming note.
