## Recommendation (source) — with adopt/reshape

**Back ISI, with one wedge:** context-mismatch checking for **human-tissue immunology evidence**, starting with **RA synovium**.

| Element | Source | Decision vs existing strategy |
| ------- | ------ | ----------------------------- |
| Why ISI | Narrow; best-in-class in 90 days; no NHS procurement / patient data; benchmarkable; complements platforms | **Adopt** — matches ISI-first + prior Owkin/BenchSci entry |
| User | Translational scientist / evidence lead in I&I biotech/pharma, or academic synovial-biopsy group | **Adopt** as design-partner persona |
| Workflow | Target/biomarker evidence review for RA synovium; separate human-tissue vs mouse / blood / cell-line | **Adopt as Stage-1 wedge**; reshape vs melanoma Explorer as **signature demo** — dual-track: RA checker + melanoma product surface (see [HSI_IMMUNOLOGY_SI_BUILD_PATH.md](./HSI_IMMUNOLOGY_SI_BUILD_PATH.md)) |
| Proof point | ≥85% per-dimension tag accuracy on 200 expert-labelled RA abstracts; fewer missed mismatches in timed reviewer study | **Engineering / eval targets** — not current performance |
| Route to market | Design partners first; then skill/MCP inside Owkin K Pro or Claude-like tools | **Adopt as Proposed** — no invent partnership |
| Aksh for 90 days | Maintenance; one shadow-mode pilot only if inbound; **no new agents**; reuse named-reviewer gate / honesty strip / Shield audit in ISI review; contacts → reviewers now, clinician labels later | **Adopt posture** — Aksh clinical runtime stays out of HSI substrate |
