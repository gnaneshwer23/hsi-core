# HSI-BENCH-IMMUNO v1.0 — P1-B acceptance protocol

**Status: engineering protocol candidate; scientific acceptance BLOCKED.** There are 120 allocated final authoring slots, **zero real cases authored/adjudicated by this change**, no invented expert identities or gold, no scientific quality floors approved, and no final provider evaluation. Tests contain explicitly synthetic engineering fixtures only. This document proposes a protocol for named scientific approval; committing it is not scientific preregistration or acceptance.

## Case and review requirements

Every private canonical case must contain question/task/domain/layer/risk, biological claim and estimand, permitted answer boundaries, source/context records, missingness, publication/study families, biological-claim families, near-duplicate-question families, legacy aliases and a sealed external gold reference/hash. Passage-linked context reuses P1-A's seventeen fields, exact spans, source/version/hash and receipt reference. Source rights are never inferred from a URL or an unsigned licence flag. Empty/denied-evidence governance tasks require an independently checked evidence-disposition/search receipt; do not invent source passages to fill a schema. Clinical/PHI adversarial inputs must use approved fictional markers, never real PHI.

The restricted gold record contains expected conflict/answerability/abstention behavior, rationale, provenance and safety criteria, two independently authored expert assessments and adjudication. Each assessment has a distinct authenticated reviewer, expertise declaration, conflicts declaration, assessment hash and immutable receipt. The adjudicator is independent of both assessors. Review services must verify active grants, relevant expertise, actual conflict handling, assignment independence and receipt-to-case/gold binding. Strings or self-declared reviewer fields cannot establish authority. The freeze preparer requires independently operated expert/source/protocol callbacks; it does not provision that service or sign its own approvals.

**Proposed dispute rule, to approve before authoring:** adjudicate disagreements against cited passages and explicit uncertainty. If unresolved, exclude before freeze, record the reason and replace within the same allocation/risk stratum. Publish exclusion counts/reasons without leaking answers. Re-review replacement provenance and family splits. Exactly 120 resolved final cases must remain. Do not discard hard failures or disputed labels after seeing model results. Any post-freeze correction creates a new benchmark version and invalidates the old run lock; retain the prior manifest and failure record.

## Holdout custody, freeze and contamination

Actual questions, answers, rationales, source annotations and reviewer identities belong in an external access-controlled vault with separate curator/evaluator roles and audit logs. `.gitignore` is only an accidental-copy precaution; it is not access control. No real holdout payload is committed or copied into public site assets, retrieval indexes, tuning data, examples or agent system prompts. Final authorized evaluation necessarily presents the case question to the model; it never presents gold, expected behavior or expert context annotations. The evaluator explicitly whitelists question/task and run/retrieval/budget references. Do not give it the full private canonical case.

The public protocol contains allocation slots and hashes only. A signed final manifest may publish opaque case commitments, protocol/rubric/threshold/split/exclusion/contamination hashes and approval receipt references, never gold contents or identifying reviewer details. Gold commitments should include vault-held random nonces to resist dictionary attacks on short answers. `prepareImmunoFreeze` returns a hash-bound **candidate**, not a durable, signed authoritative freeze. Its expert/source checks cover development as well as holdout. An independently controlled store must retain immutable versions, restrict access, sign/timestamp the freeze and record all access. Such storage/authority is not supplied by this PR.

Split by underlying publication/study family, biological claim and near-duplicate question. Shared family IDs across development/holdout fail preflight, as do normalized/lexically near-duplicate cross-split questions. Curators must resolve DOI/PMID/preprint/publication/companion-study families and semantic paraphrases; lexical similarity alone cannot establish clean splits. Maintain transitive family groups, not row-ID disjointness. Grouped uncertainty calculations use connected study/claim/question families.

Contamination evidence must inventory all public assets, prompt/example bundles, indexes, development/tuning snapshots and previous evaluation exposures, with version hashes. An authorized vault-side scanner uses substantial gold fingerprints and heldout questions; it reports case IDs/surfaces, never copies leaked answers into logs. The repository check detects non-null structured gold fields in public JSON and exact public protocol drift. **It cannot prove no semantic, encoded or historical leakage** and must not stand in for the independent signed contamination receipt. Scan generated site output again after build. A leak blocks the locked run; investigate and replace affected families before a new freeze.

Later runs require a curator-controlled rotating unseen pool, recorded exposure history and new epoch manifests. Merely renaming the same case IDs is not rotation. Do not tune on a revealed holdout result then reuse it as unseen evidence. The rotation schedule, pool size, case retirement, exclusion ledger and source-retraction policy need preregistration with the protocol; no unseen pool is fabricated here.

## Eight quality dimensions: independently scored 0–5

These are proposed rubric anchors, to be reviewed and hash-locked before final tuning/evaluation. Each dimension is separate; never multiply a quality average by a safety indicator. Provenance and safety are independent hard gates. Existing nine-field independent-evaluation scorecards are legacy diagnostics, not a substitute or a silently averaged conversion.

| Dimension | What the reviewer assesses |
| --- | --- |
| Retrieval | Relevant supporting, opposing and null evidence retrieved under the fixed corpus/cutoff/budget; recall denominator is the curated relevant-source set |
| Mechanism accuracy | Biological claim/estimand correctness; no unsupported causal or translational bridge |
| Context preservation | Species/system/tissue/cell state/phenotype/intervention/dose/timing/assay/cohort/controls/uncertainty and missingness |
| Conflict classification | Five-class candidate classification after entity, estimand and context comparability; no contradiction from polarity alone |
| Explanation | Clear, passage-grounded explanation distinguishing findings, inference and limits |
| Uncertainty | Calibrated language, justified abstention and explicit search/context limitations; no invented numeric confidence |
| Gap quality | Specific consequential unknowns, discriminating next evidence and realistic controls; no absent-search consensus |
| Brief usefulness | Expert-rated utility of the versioned brief for a bounded research decision, without clinical recommendations |

Shared ordinal anchors: **0** absent or materially misleading; **1** major errors/omissions; **2** partial with substantial limitations; **3** largely correct with material correctable gaps; **4** correct/useful with minor gaps; **5** fully meets the case-specific evidence and rubric requirements. Dimension-specific gold examples and counterexamples must be separately authored on development data, reviewed and sealed before final tuning. A null score means unscored/not applicable, never zero or an implicit pass. Report scored and missing denominators and all six score bins. Collect separately blinded ordinal rating records. The reporter provides exact agreement, mean absolute difference and quadratic-weighted kappa for each of the eight dimensions, separately from categorical conflict agreement; missing or degenerate pairs remain explicit.

Legacy crosswalk: context accuracy → context preservation; contradiction retrieval → retrieval plus conflict classification (separate); gap precision → gap quality; abstention quality → uncertainty; brief completeness/usefulness → brief usefulness; citation identity/support and unsupported claims → provenance/support diagnostics/hard gates. Mechanism accuracy and explanation need their own ratings. No legacy rating is numerically copied into a different dimension automatically.

## Locked comparison and metrics

Compare deterministic/current baseline, single-verifier and dual-verifier configurations. Lock deployment/prompt/configuration hashes, source cutoff/retrieval snapshot policy, identical retrieval access/results per case and the same total budget cap. Dual verification must share that cap, not receive extra retrieval or an unreported cost allowance. Disclose actual tokens/cost/latency, failures, cancellations and any unequal resource use. Execution and assessment receipts must independently verify actual provider completion and limits, rather than trusting a requested configuration hash. Randomize or preregister execution order to control drift; a correction/new deployment requires a new run/version.

The disabled-by-default evaluator requires a frozen inventory, unchanged preregistered threshold policy, a dated run lock and independent readiness authorization. That authorization must verify P0-B approved providers, budgets, current source rights, P1-A integration, scientific signoff, freeze-before-final-tuning chronology and signed contamination evidence. No production flag is set. Callbacks must use hardened P0 services, persist redacted receipts and implement shared quotas and per-request bounds. A global deadline/cancellation fences later stages, but cannot undo an already completed non-cooperative request. Recover uncertain completions from durable receipts before retry; never automatically replay expensive calls. This PR supplies contracts and offline tests, not real provider adapters or a live acceptance run.

Report all three configurations and every layer/domain/risk subgroup, including zero-denominator groups. Retain case-ID diagnostic failures for false support, missed retrieval, conflict/answerability errors, incorrect context fields and unscored dimensions, separately from hard gates and operational failures. Per-case grade thresholds need their own preregistered rules; an aggregate floor is not a per-case pass label. At minimum:

- Support precision: true supported predictions / all supported predictions. False support among supported predictions: false supported / all supported predictions. False-positive rate: false supported / all gold-unsupported evaluated claims. Preserve all three denominators and counts.
- Retrieval recall: retrieved relevant identifiers / all curated relevant identifiers. A zero reference denominator is undefined, not perfect recall. The same relevance/cutoff universe must apply across arms.
- Five-class conflict confusion matrix, per-class TP/FP/FN and fixed-five-class macro-F1. Unclassified predictions count as missed gold labels. Absent classes remain explicit; fixed-five F1 uses zero for an undefined class, not selective omission.
- Context-field correct/evaluated counts; missingness precision/recall with TP/FP/FN. Report every context field separately, with a four-state missingness confusion matrix and per-field accuracy/missingness precision/recall. Aggregates cannot prove every field works.
- Answer/abstention coverage and appropriate answer-vs-abstention counts; separate accuracy at each coverage level.
- Inter-rater exact categorical agreement and Cohen's kappa, with undefined degenerate cases retained. Include raw blinded rating/disagreement denominators in the restricted report, not reviewer identities in public assets.
- Per-case elapsed time and measured cost, overall and by subgroup. Failed/partial runs remain in the intended-to-evaluate inventory. Unknown execution/assessment failures retain case/configuration/stage codes and missing-observation IDs without raw errors or invented ratings. Cost/latency summaries explicitly name unmeasured case IDs and cover observed receipts only; unknown charges are not zero. Resolve them from durable provider receipts before acceptance, rather than presenting a success-only mean as complete operating cost.

The reporting utility supplies Wilson 95% intervals as an explicitly independent-trials sensitivity calculation and reproducible 500-resample study/claim/question-family cluster-bootstrap percentile intervals for metric/score means, macro-F1, agreement, latency and cost. Fewer than two clusters yields no interval. Sparse/degenerate bootstrap intervals can be unstable or zero-width. A methodology reviewer must lock the interval method, sampling unit, resample count, handling of absent classes, multiple subgroup comparisons and applicability before the final run; do not choose the interval after results. Relevant definitions: [NIST proportion intervals](https://itl.nist.gov/div898/handbook/prc/section2/prc241.htm), [scikit-learn Cohen's kappa](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.cohen_kappa_score.html).

Even zero observed critical failures in 120 independent Bernoulli cases has a one-sided exact 95% upper failure-probability bound of about **2.47%** (`1 - 0.05^(1/120)`). Correlated cases and tiny disease subgroups give less assurance. This bound is descriptive under its assumptions, not a safety claim or accepted error budget. More independent cases may be necessary.

## Acceptance gate and ownership

Scientific lead + independent methodologist approve numeric quality floors/error budgets, which dimensions apply in each subgroup/risk class, minimum sample sizes, confidence-bound vs point-estimate criteria, dispute/exclusion rule, rotation plan and rubric **before final tuning/evaluation**. The schema requires all eight overall dimensions plus diagnostic/error metrics and explicit per-layer/domain/risk rules; it contains no default scientific floors. Not-applicable subgroup metrics require an approved reason, never fabricated values. Baseline arms report honestly even if they fail thresholds; the policy must name which candidate arm(s) must satisfy release criteria. The threshold policy names one or both verifier configurations for release-quality gates; baseline scores are reported for comparison. Missing observations and provenance/source/critical-safety gates are checked for every arm. No computation grants scientific approval.

Exit requires exactly 120 resolved/adjudicated final cases in the allocation, independently verified source permissions for every use, 100% traceable asserted material claims, zero critical safety/isolation/promotion failures and independent confirmation of all preregistered floors/budgets. Publish failures with case IDs, denominator counts, intervals and subgroup results, using a restricted report when small cells could reveal holdout labels. Never silently remove a failed case or turn missing observations into a pass. Independent scientific acceptance is a separate signed decision; an engineering computation cannot promote graph records or claim universal immunology/clinical safety.
