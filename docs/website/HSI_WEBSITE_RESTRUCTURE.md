## Design tokens

Navy #101D2A, ivory #F4F6F3, teal #297E80, sage #C8D7D3. Existing locally hosted Red Hat Display headings and Host Grotesk body, with readable line lengths. Asymmetric hero; measured editorial sections; interactive comparison as the main instrument. Avoid repeated generic card grids, stock-image sections and invented metrics. SVG relationships remain explicitly candidate/synthetic; no independent scientific result is implied.
