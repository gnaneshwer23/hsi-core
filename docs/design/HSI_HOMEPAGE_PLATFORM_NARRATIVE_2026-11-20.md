# HSI homepage platform narrative (20 November 2026)

**Intent:** Express the existing HSI scientific vision with Palo Alto–style platform storytelling clarity — without changing product scope, inventing capabilities, or marketing historical named modules.

**Reference:** Complex platform communicated as one vision → connected system → proof → clear CTAs. For HSI, scientific credibility (real graph, worked conflict, honesty labels) stays at the centre.

1. **Hero** — Brand + “Biology is connected…” + Explore platform / Scientific workbench  
2. **Published snapshot strip** — real graph counts only  
3. **Challenge + vision** — fragmented evidence → connected understanding  
4. **Scientific intelligence journey** — evidence → verification → graph → investigation → decisions (scroll-aware rail)  
5. **Worked conflict** — real investigation proof already on the page  
6. **Domains** — six scientific domains with unequal-depth honesty  
7. **Pillars + claim anatomy** — how HSI differs from search  
8. **Open questions** — live gaps  
9. **Research home** — onboarding path preserved  
10. **Trust / limits** — transparency before close CTA
