## Prioritised delivery and dependencies

1. **P0 / this slice:** reconcile audit/documents and retain scientific boundaries; establish baseline; six-department projection, bounded represented search and exact-context continuity. No ingestion or live execution.
2. **P1 foundation:** reviewed entity/disease ontology pack with source licence/version/identity collisions; reconcile candidate→governed schema adapter without copying approval. Depends on independent curator/source-policy decisions. Add server query pagination against accepted persistence scope, not a second graph database.
3. **P2 explorer:** department-specific, data-derived facets, selected-context disclosure and scalable layouts. Continue bounded traversal; measure latency/density before adding infrastructure. Depends on P1 schema; UI work may proceed with labelled synthetic fixtures.
4. **P3 agents:** server-bound selected context and investigator/verifier journey. Depends on approved source service/provider deployments (Next-A), real-account isolation (Next-B), scoped server context and reviewed ontology/source packets. Coordinate with PR #327. Use orchestrator + evidence/context investigator + verifier; optional planner only after ablation. Thirteen names describe responsibilities.
5. **P4 saved research:** cross-domain immutable investigation versions, comparison, timeline and brief. Depends on independently accepted schema scope and reviewer grants; no batch lifting of 022–030 holds.
6. **P5 release:** source/provider smoke, two-account acceptance, locked 120-case immunology benchmark, operational soak/recovery/restore and exact-SHA release packet. Depends on all earlier acceptance, named security/operations owners and scientific sign-off. Expand only after observed pilot failures are resolved.

Independent work: ontology/source curation, private benchmark/expert preparation and explorer rendering can proceed with explicit contracts. Provider wiring belongs to its open PR; no concurrent edits were made there. No additional agent services are required to remove human approval dependencies.
