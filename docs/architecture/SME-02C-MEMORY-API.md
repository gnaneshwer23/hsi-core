# SME-02C API contract
Unmounted, disabled by construction. No runtime DB adapter, no route registration.
Operations defined in src/server/scientificMemoryApi.ts. Future implementation must use server verified session, database membership, CSRF protection for cookie-authenticated writes, bounded JSON, strict schema validation, parameterised procedure calls, expected version and request id. Never accept owner identity from body. Tenant/scope selectors are untrusted and checked in DB. No raw tokens or content in logs. No caching. Return generic denial for inaccessible records. Export/correction/list require separate approved procedures; correction never promotes a scientific claim. All six scientific domains use the same contract. Live activation requires SME-02B acceptance including Neon preview, replay-safe idempotency, retention and independent security review. Disposable PostgreSQL success is not live Neon acceptance.
