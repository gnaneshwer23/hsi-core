## Candidate acceptance

This SQL is deliberately outside the migration runner. It stores unverified decision labels and three provenance entries for synthetic DOI/version labels only. It is not an authenticated observation registry. Exact request replay is allowed; conflicting reuse fails. No update/delete procedure or runtime grants are provided. Before integration, restrict the writer role, validate all envelope fields and notice references, retain linked observations and conflict reasons, and test exact replay, concurrent inserts, unauthorized reads/writes, forced RLS, duplicate authorities and false trust flags in disposable PostgreSQL. Raw response retention, source authentication, version verification and independent review remain separate gates. Do not activate on Neon or expose to clients.
