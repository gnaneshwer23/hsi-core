# Draft research coverage

Source inputs are `protocols.v1.json` and `registry.snapshot.v1.json`. The initial three protocols are draft research designs; existing seed citations are background pointers only. No registry records, verified indication-specific supporting passages or scientific approvals are supplied.

Run `bun --no-env-file run coverage:build` to regenerate, or `coverage:check` for a read-only check. The catalogue, readiness and review-preparation files are mirrored to the site, with pinned catalogue versions retained. Review packet identities/decisions stay unassigned.

See [Phase G scope, commands, acceptance gates and data replacement](../../docs/PHASE_G_RESEARCH_COVERAGE.md). Do not copy arbitrary publications, clinical records, patient data or trial eligibility claims into these files. Source and scientific review gates remain separate from metadata completeness and content hashes.
